# 일본 8대 지방 · 47개 도도부현 인터랙티브 역사·지리 아틀라스 (Japan Atlas)

> **`https://japan.nalm.info`** (또는 `https://nalm.github.io/japan-map/`)  
> 일본의 47개 도도부현(1都 1道 2府 43県)을 실제 지리 벡터 지도(SVG) 위에 투영하고, 옛 율령국(令制国)과 천년 황도·막부 권력 이동, 조선통신사 10대 사행로 및 한일 교류사, 신칸센·3대 메트로폴리스 산업 벨트를 시각화한 인터랙티브 아틀라스 웹 애플리케이션입니다.

---

## 🌟 주요 특징 (Key Features)

### 1. 🗾 실제 지리 SVG 벡터 지도 & 오키나와 확대 인셋
- 기존 47개 단순 사각 타일 그리드에서 벗어나 실제 일본 열도의 지리적 형상을 정밀하게 반영한 고해상도 SVG 벡터 폴리곤 지도
- 혼슈·홋카이도·시코쿠·규슈 4대 본섬과 함께, 우하단에 류큐제도(오키나와현) 전용 인터랙티브 확대도(Inset) 탑재
- 마우스 휠 부드러운 확대/축소(Zoom), 포인터 드래그(Pan), 지리구별 자동 카메라 포커싱

### 2. 👑 5대 테마 렌즈 (Interactive Lenses)
- **🗺️ 기본 지도 (Default Atlas)**: 8대 지방(홋카이도, 도호쿠, 간토, 주부, 긴키, 주고쿠, 시코쿠, 규슈·오키나와) 행정구역 및 현청소재지 탐색
- **👑 역대 권력 & 시대 타임라인 (Dynasty & Power Timeline)**: 고대 아스카·나라(헤이조쿄) → 헤이안(교토 황도) → 가마쿠라 막부 → 무로마치 막부 → 센고쿠 통일 → 에도 막부(도쿄) → 메이지 유신으로 이어지는 권력 중심 도도부현 하이라이트
- **🇰🇷 조선통신사 & 한국사 교류 (Korean Ties)**: 부산 왜관 출발부터 쓰시마·이키·시모노세키·세토내해(도모노우라·우시마도)·오사카·교토·에도성까지 이어지는 **10대 기착지 공식 사행로(애니메이션 점선 폴리라인)** 및 고대 도래인·도공·독립운동 사적 연계
- **🚄 신칸센 & 3대 대도시권 (Shinkansen & Pacific Belt)**: 도카이도, 산요, 규슈, 도호쿠, 호쿠리쿠 5대 신칸센 노선 오버레이 및 수도권·게이한신·주쿄권 태평양 공업벨트 시각화
- **♨️ 세계유산 & 온천·특산품 (Heritage & Onsen)**: 유네스코 세계문화·자연유산 등재 지자체 및 일본 3대 명천과 향토 미식·특산품 탐방

### 3. 🏛️ 3대 심층 모달 다이얼로그
- **행정 계층 & 율령국 체계 모달**:
  - `1都(도쿄) 1道(홋카이도) 2府(오사카·교토) 43県` 광역 지자체
  - 20개 정령지정도시, 62개 중핵시, 도쿄 23개 특별구의 특례 행정 자치 구조 및 한국 행정구역(특별시·광역시·도) 1:1 비교
  - 고대 68개 율령국(令制国)과 오기칠도(五畿七道), 사쓰마·조슈·오와리·가가 등 막말 번(藩)과 현대 현의 매핑
  - 동일본(50Hz) vs 서일본(60Hz) 전력 주파수 분할선 및 간토 vs 간사이 문화 차이 비교
- **1:1:1 지표 비교함 (Compare Drawer)**:
  - 최대 3개 도도부현 동시 비교
  - 큐레이션 추천 프리셋(3대 메트로폴리스, 천년 고도와 고대 수도, 메이지 유신 서남 웅번 삿초히, 통신사·도공 교류 거점 등) 원클릭 로드
- **통계 랭킹 모달**:
  - 인구(만 명), 면적(km²), 인구밀도(명/km²) 실시간 오름차순/내림차순 정렬 및 검색 필터

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Pretendard 웹폰트
- **Icons**: Lucide React
- **Map Data**: Natural Earth / GADM 기반 일본 47개 도도부현 GeoJSON 정밀 축약 SVG 경로 (`japanMapPaths.ts`)

## 🚀 로컬 개발 및 빌드

```bash
# 종속성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드 (TypeScript 컴파일 + Vite 최적화 번들링)
npm run build

# 빌드 결과물 로컬 미리보기
npm run preview
```
